Project Description and Credits

About This Digital Edition

This website presents a scholarly digital edition of BM EA 10473,1, combining high-resolution imagery with detailed palaeographic analysis. The project utilises IIIF standards for interoperability and Mirador 3 for interactive viewing.

Technology

  • IIIF Manifest: Custom-built annotation-rich manifest with hieroglyphic sign data
  • Viewer: Mirador 3 (open-source IIIF viewer)
  • Annotations: OA-compatible annotations with Gardiner sign classifications
  • Hosting: GitHub Pages
